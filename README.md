# SHAMIKH | شامخ - Men's Fashion Brand

موقع إلكتروني لبراند الملابس الرجالية **شامخ** - بناية عربية/إنجليزية مع نظام طلبات متكامل.

## المميزات
- واجهة عربية/إنجليزية (ثنائية اللغة)
- نظام سلة تسوق متكامل
- إرسال الطلبات عبر واتساب والبريد الإلكتروني
- لوحة إدارة للطلبات مع تخزين محلي
- تصميم أسود وذهبي فاخر
- متجاوب مع جميع الأجهزة

## كيفية الرفع على GitHub Pages

### 1. إنشاء مستودع على GitHub
- ادخل على [github.com](https://github.com) وسجل دخولك
- اضغط على **New Repository**
- اسم المستودع: `shamikh` (أو أي اسم تريده)
- اختار **Public**
- اضغط **Create Repository**

### 2. رفع الملفات
افتح **Terminal** أو **CMD** وشغل الأوامر دي بالترتيب:
```bash
cd "C:\Users\Z3TR\Desktop\Shamikh-Brand"
git init
git add .
git commit -m "Initial release - Shamikh brand site"
git branch -M main
git remote add origin https://github.com/اسم_المستخدم/shamikh.git
git push -u origin main
```

### 3. تفعيل GitHub Pages
- روح على **Settings** > **Pages**
- تحت **Branch** اختار **main** و **/(root)**
- اضغط **Save**
- بعد دقايق، السايت هيكون متاح على: `https://اسم_المستخدم.github.io/shamikh`

## إضافة لوجو البراند
- احط صورة اللوجو في مجلد `images/` باسم `logo.png`
- أو عدل في الـ HTML عشان تستخدم صورتك

## استقبال الطلبات
الطلبات بتتنبهك على:
1. **واتساب**: بتفتح محادثة واتساب تلقائياً مع تفاصيل الطلب
2. **الإيميل**: بتفتح بريدك الإلكتروني مع الطلب جاهز للإرسال
3. **لوحة الإدارة**: كل الطلبات محفوظة في المتصفح (اضغط على زر ⚙️ في الزاوية)

## تعديل المنتجات
افتح ملف `js/products.js` وعدل أو زود المنتجات زي ما تحب.
